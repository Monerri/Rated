# Fonts

Fraunces (headings, with italics), DM Sans (text and buttons) and IBM Plex Mono (evidence such as company numbers and dates). Latin subset, WOFF2, variable where available, from the Fontsource packages on npm (version 5.3.0 for Fraunces and DM Sans). All three are licensed under the SIL Open Font License 1.1, which allows bundling them with the site.

They're stored here so builds never depend on downloading fonts from Google.
